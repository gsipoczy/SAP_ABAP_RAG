&FUNCTIONALITY&
This method allows the data of service entry sheets to be checked.
&EXAMPLE&

&HINTS&
<ZH>Transfer</>
The entry sheet header data is passed on in the parameter
<LS>EntrySheetHeader</>. The account assignments are passed on in the
table <LS>EntrySheetAccountAssignment</>. Service data relating to the
PO item can be passed on in the tables <LS>EntrySheetServices</> and
<LS>EntrySheetSrvAccAssValues</>.
<ZH>Return messages</>
Messages are returned in the table <LS>Return</>.
&FURTHER_SOURCES_OF_INF&

&FUNCTIONALITY&
You can use this method to output the detailed data on a service entry
sheet.
&EXAMPLE&

&HINTS&
The following authorization objects are checked with the activity 03
(Display):

<DS:UO.M_BEST_BSA>M_BEST_BSA</>,,Document type in purchase order
<DS:UO.M_BEST_EKG>M_BEST_EKG</>,,Purchasing group in purchase order
<DS:UO.M_BEST_EKO>M_BEST_EKO</>,,Purchasing organization in purchase
order
<DS:UO.M_BEST_WRK>M_BEST_WRK</>,,Plant in purchase order

<ZH>Error handling</>
If error messages are issued during the processing, they are returned
in the table 'Return'. This table also logs information messages.
&FUNCTIONALITY&
This method allows you to list service entry sheets. You pass on the
desired selection criteria (e.g. purchasing group, plant, supplier) in
the import parameters. For more information, refer to the relevant
parameter documentation.
&EXAMPLE&

&HINTS&
The following authorization objects are checked with the activity 03
(Display):


<DS:UO.M_BEST_BSA>M_BEST_BSA</>,,Document type in purchase order

<DS:UO.M_BEST_EKG>M_BEST_EKG</>,,Purchasing group in purchase order

<DS:UO.M_BEST_EKO>M_BEST_EKO</>,,Purchasing organization in purchase
order

<DS:UO.M_BEST_WRK>M_BEST_WRK</>,,Plant in purchase order
<ZH>Return</>
The entry sheets that satisfy the selection criteria are returned in the
table 'ENTRYSHEET_HEADER'.
<ZH>Error handling</>
If error messages are issued during the processing, they are returned in
the table 'Return'. This table also logs information messages.

&FUNCTIONALITY&
This method allows you to release entry sheets.
The entry sheet number and the release code must be passed on. The new
release status and the new release indicator are returned.
&HINTS&
The authorization object <DS:UO.M_EINK_FRG>M_EINK_FRG</> is checked.

&FUNCTIONALITY&
This method allows you to cancel the release of entry sheets. The entry
sheet number and the release code must be passed on. The release status
and the release indicator valid prior to the release are returned.
&HINTS&
The authorization object <DS:UO.M_EINK_FRG>M_EINK_FRG</> is checked.

&FUNCTIONALITY&
You can use this method to create service entry sheets.
&HINTS&
The following authorization objects are checked with the activity 76
(entry of services performed).

<DS:UO.M_BEST_BSA>M_BEST_BSA</>,,Document type of purchase order of
entry sheet
<DS:UO.M_BEST_EKG>M_BEST_EKG</>,,Purchasing group of purchase order
<DS:UO.M_BEST_EKO>M_BEST_EKO</>,,Purchasing organization of purchase
order
<DS:UO.M_BEST_WRK>M_BEST_WRK</>,,Plant of purchase order
<ZH>Transfer</>

The header data of the entry sheet is passed on in the parameter
'EntrySheetHeader'.

The account assignments are passed on in the table
'EntrySheetAccountAssignment'.

The service data for the service entry sheet can be passed on in the
tables 'EntrySheetServices' and 'EntrySheetSrvAccAssValues'.
All value and price fields are to be passed on in the currency of the
purchase order.
<ZH>Return messages</>
Messages are returned in the table 'Return'.
