&FUNCTIONALITY&
This BAPI function module is used to create object references for a
partner sales activity in order to assign objects to a partner sales
activity subsequently.
The data base change will only be initiated by the method
BapiService.TransactionCommit.
The relevant method has been implemented as a class method. The return
parameter contains the processing log. It contains all messages (error,
warning, information) from the consistency check.

&FUNCTIONALITY&
This function module selects sales activities and sends them
asynchronously via ALE. The receiving system calls the
<ZH>SaveReplicaMultiple</> method.
The InitialDownload parameter has priority over the SalesActivityID
parameter.
&FUNCTIONALITY&
The system uses the transmitted ALE message type (<ZH>MessageType</>
parameter) to read and evaluate all ALE change pointers. The output is
packed in IDocs and transmitted asynchronously to the ALE service. This
service calls the <ZH>SaveReplicaMultiple</> method in the target
system.

&FUNCTIONALITY&
You can use one of the intervals of the organizational units or the
<ZH>SDOrganizationalUnits</> parameter to select data.
Priority rule:
SDOrganizationalUnits
Multiple selection
If all selection parameters are filled, the resulting quantity is the
cross product of the organizational units.
For example, you have defined the following selection criteria:
Sales organization:   0001
Distribution channel: 01 - 04
The system takes all possible combinations of these criteria into
account:
Sales organization 0001 Distribution channel 01
Sales organization 0001 Distribution channel 02
Sales organization 0001 Distribution channel 03
Sales organization 0001 Distribution channel 04

&FUNCTIONALITY&
This BAPI function module saves partner sales activities which have
been placed in the global memory with the following methods:
CreateFromDataMultiple
ChangeMultiple
DeleteMultiple
The relevant method has been implemented as a class method. The system
returns the keys of the created objects in the <ZH>SalesActivityBOID</>
parameter. Note that follow-up activities are also created. The
<ZH>Return</> parameter contains the processing log. The log contains
all messages (error, warning, information) from the consistency check.

&FUNCTIONALITY&
You can use this BAPI function module to create partner sales
activities. In order to change the database, the following methods have
to be called:
BusPartnerContact.Save
BapiService.TransactionCommit
The relevant method has been implemented as a class method. The
<ZH>Return</> parameter contains the processing log. The log includes
all messages (error, warning, information) from the consistency check.
Assignment of key fields:

Create with reference to an external reference object
<ZH>REFOBJECTTYPE</> Object type of reference object, here "PROXY0001"
or subtype
<ZH>REFOBJECTKY</>   Key of reference object type
DOC_NUMBER      not relevant
REFDOCTYPE      not relevant
<ZH>REFRELTYPE</>    Binary relationship type, here 'VORL'
The generated object reference can be displayed in the sales activity.

Create with reference to an internal reference object
<ZH>REFOBJECTTYPE</> Object type of reference object
<ZH>REFOBJECTKY</>   Key of reference object
DOC_NUMBER      not relevant
<ZH>REFDOCTYPE</>    Sales activity type of reference object (only if
reference = sales activity)
<ZH>REFRELTYPE</>    Binary relationship type
The generated object reference can be displayed in the sales activity.

Create without reference to a reference object
REFOBJECTTYPE   blank
REFOBJECTKY     blank
<ZH>DOC_NUMBER</>    Handle
REFDOCTYPE      not relevant
REFRELTYPE      blank
The fields REFOBJECTTYPE, REFOBJECTKY and DOC_NUMBER are internally
identifying for an instance!
