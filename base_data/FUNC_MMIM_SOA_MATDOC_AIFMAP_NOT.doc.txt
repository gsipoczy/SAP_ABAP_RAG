&FUNCTIONALITY&
By creating a purchase order an external partner (for example Ariba
network) can trigger a goods movement in the SAP system like S/4HANA or
SAP HANA Cloud Platform.
This goods movement will be stored by a material document in the
suitable database.

As reply on the goods movement a conformation will be sent to the
external partner which send the material document request.
This function module will be called in the AIF process which is
responsible for the mapping and sending of the conformation to the
external partner.

The task of this function module is to receipt the generation of a
material document. As response with material document number and the
creation date is sent.
Beside that the function module offers the possibility to do further
mappings by calling an internal or external BADI.
The internal BADI is reserved for extensions by SAP, the external BADI
for extension by the customer.

& FUNCTIONALITY
By creating a purchase order an external partner (for example Ariba
network) can trigger a goods movement in the SAP system like S/4HANA or
SAP HANA Cloud Platform. This goods movement will be stored by a
material document in the suitable database.
As reply on the goods movement a conformation will be sent to the
external partner.
Furthermore a notification can be sent to relevant receivers dependent
on the customizing done in the output management.
This function module will be called in the AIF process which is
responsible for the mapping and sending of the notification to the
relevant receivers.
The task of this function module is to determine certain material
document dependent data from the database and to map the data in the
corresponding fields of the notification.
Beside that the function module offers the possibility to do further
mappings by calling an internal or external BADI. The internal BADI is
reserved for extensions by SAP, the external BADI for extension by the
customer.
