&FUNCTIONALITY&
The function module contains the determination and the call of the
program for printing a letter with the corresponding output media.
Furthermore, the request data are stored in the ABAP memory. The called
program can store an error code in the ABAP-Memory, which will then be
processed.

request data are stored in the ABAP memory. The called program can
store an error code in the ABAP-Memory, which will then be processed.

&FUNCTIONALITY&
The function module contains the determination and the calls of the
function modules
1. to print a letter for the corresponding output media
2. the output of the output media themselves
The table KONV_TAB contains all information of the request data.
