&FUNCTIONALITY&
This function module selects material stocks from different plant
storage locations based on selected import parameters. It then exports
the information to different tables. This function module does not
support stocks related to industry sector, it only supports core
functionality.

There are no dependencies on other function modules. This function
module can be called several times if there is a requirement to retrieve
current stocks of a material in a plant frequently.
When the function module is called by the system, the following import
parameters are by default selected:
IV_MARC
IV_MARD
IV_MCHA
IV_MCHB
IV_MSKU
IV_MSLB
IV_MSKA
IV_MSPR
IV_MBEW
IV_NULL_STOCKS
IT_MATERIAL
IT_PLANT
The null stocks for plant materials are selected if the import parameter
<LS>IV_NULL_STOCKS </>is selected. The export variables
<LS>EV_KZ_BEW_KAUFT_BEST </>and <LS>EV_KZ_BEW_PAUFT_BEST </>are included
if special valuated stock in customer orders on hand and project stock
exists respectively.
