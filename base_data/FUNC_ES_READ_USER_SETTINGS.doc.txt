Wenn eine der Eingaben IACTION, IELEMENT oder IACTIVE gefüllt sind,

in die interne Tabelle eingetragen.
Ist es schon vorhanden wird es überschrieben, sonst wird angehängt.
Ist ISAVE = X werden die Daten mit MODIFY in die DB-Tabelle ESDUS ge-
schrieben.

TOJTB)
                        z.B. 'BUS2091' für ServiceEntrySheet
                  MAXANZ      : Anzahl der anzuzeigenden Objekte

                        (optional)
                  MAXSTORE    : Anzahl der zuspeichernden Objekte
(default 100)
                        (optional)
                  IESRUO      : Tabelle in der die Ergebnisse stehen
sollen,
                        wird überschrieben

Ein/Ausgabe: IESRUO    : Tabelle mit zuletzt verwendeten Objekten,
                        zuletzt verwendetes Objekt steht oben,
                        maximal MAXANZ Einträge

Liest Daten zum Objekt und zum Benutzer von der Datenbank
und reorganisiert die Datenbanktabelle, d.h.
alle überzähligen durch es_append_user_objects hinzugefügten
Objekte werden auf der Datenbank gelöscht. MAXANZ gibt an,
wieviele Objekte zurückgegeben und MAXSTORE viele auf der Datenbank
gehalten werden.
Die Tabelle IESRUO wird zuerst leer gemacht und dann mit den gelesenen
Daten gefüllt.
An die interne Tabelle der Funktionsgruppe MLSO werden die Daten ange-
hängt.
Bei einem erneuten Lesen bevor die Daten gespeichert werden wird
gepuffert aus der internen Tabelle der Funktionsbausteine gelesen.
