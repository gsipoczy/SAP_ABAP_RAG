&FUNCTIONALITY&
This BAPI function module is used to create object references for a
partner sales activity in order to assign objects to a partner sales
activity subsequently.
The data base change will only be initiated by the method
BapiService.TransactionCommit.
The relevant method has been implemented as a class method. The return
parameter contains the processing log. It contains all messages (error,
warning, information) from the consistency check.

objects with the type "Assigned". This method can be used to remove
object references from a partner sales activity.
The data base change will only be initiated by the method
BapiService.TransactionCommit .

&FUNCTIONALITY&
This function module selects sales activities and sends them
asynchronously via ALE. The receiving system calls the
<ZH>SaveReplicaMultiple</> method.
The InitialDownload parameter has priority over the SalesActivityID
parameter.
&FUNCTIONALITY&
The system uses the transmitted ALE message type (<ZH>MessageType</>
parameter) to read and evaluate all ALE change pointers. The output is
packed in IDocs and transmitted asynchronously to the ALE service. This
service calls the <ZH>SaveReplicaMultiple</> method in the target
system.
