&FUNCTIONALITY&
MM_PO_GET_COMPONENTS ist dafür konzipiert, im Anschluss an
BAPI_PO_GETDETAIL1 gerufen zu werden. Die Komponenten-Tabelle, die
BAPI_PO_GETDETAIL1 zurückgibt, wird MM_PO_GET_COMPONENTS als Import
Parameter mitgegeben.
MM_PO_GET_COMPONENTS ergänzt nur die Daten, die ihm in der Import-
Tabelle IM_COMPONENTS mitgegeben werden. Die ergänzten Daten werden in
der Tabelle EX_COMPONENTS zurückgegeben.
Es wird nicht auf archivierte Daten zugegriffen, sondern nur auf Daten
von der Datenbank.
Ergänzt werden diese zusätzlichen Felder, die sich in der Export-Tabelle
EX_COMPONENTS finden:
ITEM_CAT (Positionstyp (Stückliste)
REQ_QUAN (Bedarfsmenge)
BASE_UOM (Basismengeneinheit)
BASE_UOM_ISO (Basismengeneinheit im ISO-Code)
PHANT_ITEM (Dummy-Positionskennzeichen)
BATCH (Chargennummer)

WICHTIG:
MM_PO_GET_COMPONENTS führt keine Berechtigungsprüfungen aus! Es wird
davon ausgegangen, dass nur Daten mitgegeben werden, für die die
Berechtigungsprüfungen bereits erfolgt sind, da BAPI_PO_GETDETAIL1 alle
erforderlichen Prüfungen durchführt.
