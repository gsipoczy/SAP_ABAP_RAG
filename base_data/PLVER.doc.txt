&FUNCTIONALITY&
The function module provides the value selection for the F4 function
for the key selection in the item entry. The origin indicator is a
prerequisite. By means of the origin indicator it is controlled which
value help shall be built up.
For the time being the following value helps are supported: material
selection, item proposals SD and product proposal list CH (if
implemented).
If the key field contains a value, a generic selection takes place.

&FUNCTIONALITY&
This function module composes the names of the master data file
respectively the request file. The name is derived from the entries in
the Customizing table for output files. The default names can be stored
- dependent on the sales organization - in the Customizing table. If
specific keywords have been marked with the * sign for the assignment
of names, they will be replaced by the relevant values:
VKORG,,=> ,,Sales organization
VTWEG ,,=> ,,Distribution channel
SPART,,=> ,,Division
VERL,,,,=>,,Distributor
MBEG,,=> ,,Report start
MEND,,=> ,,Report end
ALFNR,,=> ,,Request run number
KEYRO ,,=> ,,Value of the field 'Control Request'
DATE,,,,=> ,,System date
TIME,,,,=> ,,System time
USER,,,,=>,,System user name
All other names are copied in their original versions in the assignment
of names.

&EXAMPLE&
The entry (sales organization 0001 and distributor 4711)
ANF*VKORG*VERLEGER*VERL*.ABS
results in the file name
ANF0001VERLEGER4711.ABS
