&FUNCTIONALITY&
This function module is used to determine the rebate sales from the
info structure S469 for the extended rebate processing.
In a specified period the entire data for a condition is read from the
S469 and summed up for each variable key. Simultaneously, the data for
the whole conditon is summed up, too.
&EXAMPLE&

&HINTS&
This function module is a copy of the function module
SD_BONUS_TURN_OVER that was adjusted for the extended rebate
processing.
