&FUNCTIONALITY&
Funktionsbaustein zur Ermittlung der Abladestelle zu einem Debitor.
Es werden die Abladestellen zum übergebenen Debitor gelesen. Sollte es
mehr als eine Abladestelle geben, so wird die erste Abladestelle (laut
Datenbestand) als Default markiert und die Liste aller verfügbaren
Abladestellen alphabetisch zur Auswahl angeboten.
Sollte nur eine Abladestelle verfügbar sein oder der Parameter
FIF_NO_DIALOG = 'X' gesetzt sein oder der Aufruf im BATCH erfolgen, so
wird die erste Abladestelle (laut Datenbestand) ausgewählt.
Die gewählte Abladestelle wird zurückgeliefert.

&FUNCTIONALITY&
This function module displays the address of a partner you entered, so
that you can make changes.  When you have changed the address, the
system updates the internal data retention.
The parameter FIF_FIRST_MAINTAINING is not currently in use.
If you fill parameter FIS_VBUV by making an entry in the incompletion
log, the address screen appears in full screen mode. If possible, the
system places the cursor in the data field named in the entry.
FIF_DISPLAY_ONLY = 'X' specifies that the address cannot be changed
(display mode).
FEF_ADDRESS_CHANGED tells you whether the partner's address has been
changed.
FEF_CANCEL indicates that the user terminated the dialog.
