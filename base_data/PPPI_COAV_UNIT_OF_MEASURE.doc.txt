Processing Logic
During automatic value assignment, one of the following values is
assigned to the characteristic:
If the process instruction also contains the characteristic
PPPI_MATERIAL_ITEM, "Item number of the material component", and a value
has been assigned to this characteristic:
the quantity of the specified material component
<ZK>Exception:</> If batch determination has been carried out
for the material component, the quantity can only be determined using
the reservation item (PPPI_RESERVATION_ITEM), see below.
If the process instruction also contains characteristic
PPPI_RESERVATION_ITEM, "Item number of the reservation", and a value
has been assigned to this characteristic:
the quantity of the reserved material
If the process instruction also contains characteristic
PPPI_ORDER_ITEM_NUMBER, "Number of the order item", and a value has been
assigned to this characteristic:
the quantity of the specified order item
Otherwise:
the quantity of the material assigned in the order header
&HINTS&
In generated process instructions, the values of the specified
characteristics are assigned automatically if you use one of the
following scopes of generation:
Scope of generation,,,,,,Characteristic
For all reservations (01),,,,,,PPPI_MATERIAL_ITEM
,,,,,,PPPI_RESERVATION_ITEM
For all order items (02),,,,,,PPPI_ORDER_ITEM
For all reservations,,,,,,PPPI_MATERIAL_ITEM
and order items (03),,,,,,PPPI_RESERVATION_ITEM
Characteristic value assignment logic
During automatic characteristic value assignment, this characteristic
is assigned the unit of measure of the quantity that was assigned
automatically to a previous characteristic of the same process
instruction.
Examples
The unit of measure of the material quantity is automatically assigned
to the characteristic if a value has been automatically assigned to
one of the following characteristics of the same process instruction:
PPPI_MATERIAL_QUANTITY, "materials quantity"
PPPI_MATERIAL_PRODUCED, "quantity of material produced"
PPPI_MATERIAL_CONSUMED, "quantity of material consumed"
The unit of measure of the activity is automatically assigned to the
characteristic if a value has been assigned automatically to
characteristic PPPI_ACTIVITY ("activity to be confirmed") in the same
process instruction.
